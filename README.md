# FB Comment Automation — Releases

Repo ini **hanya berisi file rilis**. Source code tidak dipublikasikan di sini.

## Unduh installer

Buka halaman **[Releases](https://github.com/bebright27/fb-comment-automation/releases/latest)** lalu ambil:

- `FB Comment Automation-Setup-<versi>.exe` — installer Windows (NSIS, tanpa hak admin)
- `*.exe.blockmap` dan `latest.yml` — dipakai auto update, **jangan dihapus**

## Auto update

Aplikasi yang sudah terpasang memeriksa `latest.yml` dari rilis terbaru ±8 detik setelah dibuka.
Jika ada versi baru, aplikasi menampilkan notifikasi versi, mengunduh setelah pengguna setuju,
lalu memasang saat aplikasi ditutup (atau langsung lewat tombol pasang).

Versi saat ini: **1.2.0** — lihat [catatan rilis](https://github.com/bebright27/fb-comment-automation/releases/latest).
